# Social Media Image Creation Guide

## Required Images:

### 1. og-image.png (1200x630px)
For Facebook, LinkedIn, and general Open Graph

**Template**:
- Background: #0071E3 (DH Workplace blue)
- Logo: DH Workplace logo (centered)
- Headline: "Business Operations Platform"
- Subtext: "HR • CRM • Reporting"
- Call to action: "Start Free Trial"

**Create at**: https://www.canva.com/create/open-graph/

### 2. twitter-image.png (1200x600px)
For Twitter/X Card

**Template**:
- Same as above but 1200x600px ratio
- Ensure text is readable at smaller size

**Create at**: https://www.canva.com/create/twitter-post/

## Quick Canva Instructions:

1. Go to Canva.com
2. Search for "Social Media" template
3. Use custom dimensions:
   - OG Image: 1200 x 630
   - Twitter: 1200 x 600
4. Upload DH Workplace logo
5. Add text overlay
6. Export as PNG
7. Save to `/public/` folder
